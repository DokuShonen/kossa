# Figure 2 : Schéma du processus de développement (Forme en Y)

## Description pour construction de la figure

### Structure générale
Le schéma représente le **Processus Unifié (UP)** sous forme de **Y**. Les phases du projet (en haut) convergent vers les disciplines d'ingénierie (en bas), formant la lettre Y.

### Parties hautes (Phases du projet)
- **Inception** (gauche) : Définir la portée, identifier les cas d'utilisation, évaluer la faisabilité
- **Élaboration** (centre-gauche) : Analyser les besoins, concevoir l'architecture UML, planifier les itérations
- **Construction** (centre-droite) : 6 itérations (Authentification, Réclamations, Affectation, Escalades, Statistiques, Administration)
- **Transition** (droite) : Tests finaux, documentation, démonstration, soutenance

### Parties basses (Disciplines d'ingénierie)
- **Modélisation du domaine** : Compréhension métier
- **Gestion des exigences** : Captation des besoins
- **Analyse et conception** : Conception logicielle
- **Implémentation** : Développement
- **Tests** : Validation
- **Déploiement** : Mise en production

### Flux
- Les phases convergent vers les disciplines (forme Y)
- Les disciplines s'enchaînent de haut en bas
- Chaque phase active certaines disciplines

### Couleurs suggérées
- Phases : bleu clair (#E3F2FD), vert clair (#E8F5E9), orange clair (#FFF3E0), rose (#FCE4EC)
- Disciplines : mêmes couleurs que les phases correspondantes

*(Source : d'après le Processus Unifié, Jacobson et al.)*
